# ГАРАЖ 24 — сайт автосервісу

Локальний статичний сайт-візитка українською мовою. Не потребує збірки, серверної частини, бази даних чи встановлення залежностей.

## Перегляд

Відкрийте `index.html` у браузері або запустіть локальний сервер з цієї папки:

```powershell
python -m http.server 8000
```

Після запуску відкрийте `http://localhost:8000`.

## Структура

- `index.html` — весь вміст сайту та SEO-метадані.
- `styles.css` — адаптивне оформлення, анімації та мобільне меню.
- `script.js` — мобільна навігація, галерея й анімації появи.
- `assets/` — фотографії, збережені локально.
- `dist/` — готова статична копія сайту.

## Важливо

Перед запуском перевірте актуальність контактів, графіка, цін і відгуків. Google Maps та вебшрифти потребують інтернет-з'єднання.

Фотографії підібрані з Unsplash та Pexels і включені локально; фото механіка з Pexels — автор Artem Podrez.
